# CLI Specifications (`docs/specs/cli/`)

Specifications for the `install` / `i` project-resolution pipeline and the
interactive selector.

- [Target Resolution](target-resolution.md): parser, `versionID`/`fileID`
  interceptor, multi-platform matching, search fallback, non-interactive
  degradation, async metadata pipeline, and the install plan/report contract.

Related: the TUI specs under `docs/specs/tui/` share the same core submodule and
the `modbridge` metadata helpers used here.
