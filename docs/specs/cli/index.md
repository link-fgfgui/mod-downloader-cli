# CLI Specifications

Specifications for the `install` / `i` project-resolution pipeline and the
interactive selector.

- [Target Resolution](target-resolution.md): parser, version/file interceptor,
  multi-platform matching, keyword fallback, multi-target all-or-nothing
  fallback, the `--server` HTTP receiver, non-interactive degradation, async
  metadata pipeline, and the install plan/report contract.

The TUI specs under `docs/specs/tui/` share the same symlinked `core` module and
the `modbridge` metadata helpers used here.
